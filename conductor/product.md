# Initial Concept
To create a massively multiplayer game set in a world where dinosaurs still exist.

# Product Guide

## Development Focus

The primary development focus for the 'Fossil' game project in the near future will be on enhancing existing game mechanics. This includes refining and expanding core gameplay loops such as:

*   **Combat System:** Improving combat mechanics, balance, and player feedback.
*   **Crafting System:** Adding depth to crafting recipes, resource acquisition, and item progression.
*   **Resource Gathering:** Enhancing the experience of collecting resources, potentially introducing new methods or environmental interactions.
*   **Player Progression:** Ensuring that improvements to mechanics contribute to a satisfying player progression system.

This focus aims to deepen the core gameplay experience and provide a more engaging and polished interaction for players within the existing game world.
